Read README.md for conventions and the graphics pipeline (folder layout: browse `src/` – feature-based).
README screenshots live in `docs/screenshots/*.jpg` (docs/ has `.gdignore`); retake with the screenshot command below.

## Commands
- Godot console exe: `C:/ProgramData/chocolatey/lib/godot/tools/Godot_v4.7.2-stable_win64_console.exe`
- Import / check for script & resource errors: `<godot> --headless --path . --import`
- Visual check: `<godot> --path . -- --screenshot=<abs.png> --delay=3 [--lighting=day|sunset|night]` then view the PNG.

## Rules
- Fully typed GDScript (`untyped_declaration` warning is on). Autoloads have no `class_name`.
- Feature-based folders under `src/`; raw art/audio under `assets/`.
- Cross-system communication via `EventBus`; story progress via `GameState` flags.
- Jolt: physics bodies must use uniform scale.
- Do not store generated MultiMesh data in .tscn (GrassField clears it on save).
- Pixel art is generated by `python tools/art/gen_terrain.py` (PIL); map layout = small RGBA PNG (R dirt, G tall grass, B water, A=0 forest) read by TerrainGround/TerrainWater/TerrainCollision/GrassField; its .import must keep fix_alpha_border=false.
- Player sprite: `python tools/art/gen_character.py` → heroine_sheet.png + heroine_frames.tres (anims `<idle|walk|attack|dodge|hurt>_<down|up|side>`; Player picks the suffix from facing vs camera; left = flip of side).
- Current focus (per user): graphics & lighting first; no enemies yet.
